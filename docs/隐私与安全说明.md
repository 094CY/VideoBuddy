## 数据存放

平台由浏览器单页应用与一个 Express 服务组成。账号、会话、租户工作区、托管模型配置与域名白名单都经服务端存储层读写，支持两种后端：

| 后端 | 存放形式 |
|---|---|
| `file`（默认） | 服务数据目录下的 JSON 文件，写入采用临时文件加原子替换 |
| `sqlite` | Node 内置 SQLite 数据库，适合多进程共享同一份数据 |

浏览器保留工作区数据的即时缓存，键前缀统一为 `videobuddy-*`；退出登录时清除。

| 数据 | 存放形式 |
|---|---|
| 项目与工作流 | 服务端按账号隔离，浏览器缓存 |
| 上传素材 | 服务端按账号目录保存，返回同源读取地址 |
| 账号与会话 | 服务端：口令 scrypt 哈希加盐、会话 token 摘要 |
| 用量统计 | 服务端按账号隔离，浏览器缓存 |
| 团队共享模型服务 | 配置与密钥保存在服务端存储层 |
| 本机自建模型服务 | 密钥保存在当前浏览器缓存 |

数据只发送到用户登记的模型服务。登录同一账号可在任意设备继续工作；「设置 → 数据迁移」提供 JSON 备份导出与导入。

## 密钥边界

- **团队共享服务**：密钥保存在服务端，浏览器只获取脱敏后的服务与模型列表。AI 请求经 `/api/proxy` 时由服务端注入鉴权头；请求中携带的其他鉴权头会被覆盖。
- **本机自建服务**：密钥以 Base64 编码存于浏览器缓存，这不等同于加密。能够访问该浏览器存储的脚本、扩展或本机用户均可读取。
- 导出的备份 JSON 可能包含账号信息与本机自建服务的密钥，属于敏感文件。
- 导入备份前应确认文件来源，备份可以写入账号状态与模型配置。

需要多人共用同一份配置时使用团队共享服务；在公用或他人可访问的设备上不配置生产密钥。

## 代理与接口防护

`/api/proxy` 负责转发 AI 请求。目标地址须满足以下约束：

| 措施 | 说明 |
|---|---|
| 协议限制 | 仅允许 HTTPS；明文通道不发送鉴权头 |
| 地址校验 | 拦截私有、回环、链路本地、保留地址与云元数据地址 |
| 域名白名单 | 仅放行用户登记的服务域名、管理员托管的服务域名，或 `PROXY_ALLOWED_HOSTS` 显式追加的域名 |
| 重定向 | 上游返回 3xx 时不跳转 |
| 方法与请求头 | 允许 GET / POST；过滤 `Host`、`X-Forwarded-*` 等可伪造头 |
| 超时与体积 | 请求有超时上限，响应体有大小上限 |
| 配额 | 单账号每分钟 AI 代理请求数有上限 |
| 会话 | 除健康检查外，所有 `/api/*` 需要服务端会话；管理端点另需管理员角色 |
| 租户数据 | 用户 id 从会话推导，接口不接受前端指定的租户 id |
| CORS | 默认同源，仅显式配置的来源被放行 |
| 监听地址 | 默认 `127.0.0.1` |

## 账号与会话

口令至少 10 位且同时包含字母与数字，服务端以 scrypt 加盐哈希保存。会话使用 HttpOnly、SameSite=Lax Cookie，有效期 7 天；修改口令与管理员重置口令会撤销会话，每账号会话数有上限。HTTPS 部署设置 `VB_SECURE_COOKIE=1` 为 Cookie 增加 Secure 标记。

密码策略、会话列表与注销在「设置 → 个人」；登录、账号变更与会话注销写入审计日志，管理员可导出。自动备份按 `VB_BACKUP_INTERVAL_HOURS` 生成，保留最近 7 份。

## 部署

- 本地或自托管运行时，服务默认绑定本机地址
- 对外访问时前置带鉴权的反向代理并启用 HTTPS，通过 `CORS_ALLOW_ORIGIN` 限定来源
- 生产部署必须通过 `VB_ADMIN_PASSWORD` 显式设置管理员口令
- `file` 后端为单进程，启动时对数据目录加实例锁；`sqlite` 后端由数据库事务保证并发安全

## 仓库检查

提交或发布前，确认仓库里没有真实凭证、个人信息与本机路径：

```bash
# 常见密钥格式
grep -rInE "sk-[A-Za-z0-9]{20,}|AKID[A-Za-z0-9]{20,}|AIza[A-Za-z0-9_-]{20,}" \
  --include="*.ts" --include="*.tsx" --include="*.js" --include="*.json" \
  --exclude-dir=node_modules --exclude-dir=dist .

# 邮箱地址与本机绝对路径
grep -rInE "[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}|/Users/[a-z]+" \
  --include="*.ts" --include="*.tsx" --include="*.md" \
  --exclude-dir=node_modules --exclude-dir=dist .
```

命中的应只有示例域名与占位符。
